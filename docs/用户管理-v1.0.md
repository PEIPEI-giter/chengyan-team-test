# 简单用户管理 v1.0

## 目标

系统必须通过账号登录后才能访问业务数据，并提供满足团队测试所需的最小用户管理能力。

## 角色与验收

| 角色 | 能力 | 验收标准 |
|---|---|---|
| 管理员 | 登录、退出、使用业务模块、查看/新增/启停用户、调整角色 | 管理员可进入用户管理；不能停用自己或移除自己的管理员角色 |
| 成员 | 登录、退出、使用业务模块 | 成员无用户管理入口，直接请求用户接口返回 403 |

## 安全约束

- 密码使用随机盐和 `scrypt` 哈希保存，不保存明文。
- 登录成功后使用随机 HttpOnly、SameSite=Lax 会话 Cookie，有效期 12 小时。
- 停用用户时立即清理其会话。
- 不提供公开注册、找回密码、复杂组织权限和第三方单点登录。

## API

- `POST /api/auth/login`：账号密码登录。
- `GET /api/auth/me`：读取当前会话用户。
- `POST /api/auth/logout`：退出并注销会话。
- `GET /api/users`：管理员查看用户。
- `POST /api/users`：管理员新增用户。
- `PUT /api/users/:id`：管理员调整角色及启停状态。
- 除健康检查和登录接口外，所有业务 API 均要求有效会话。

# 商品数据清洗 v2

## 目标

将多份 CSV、Excel 商品材料按照可编辑的 Markdown 规则和 AI 映射逻辑清洗为统一标准。原始数据始终保留，人工仅复核最终结果，必要时修改标准名称或规格后确认入库。

## 核心流程

1. 上传多份 `.xlsx`、`.csv` 材料，展示文件名、格式、大小、记录数、字段数和读取状态。
2. 编辑 Markdown 清洗规则。只有保存后的版本可以执行清洗，每次保存生成新版本。
3. 完整保留并展示所有来源材料的原始数据。
4. 生成数据诊断报告，识别名称、规格单位、大小写和编码体系差异。
5. 展示数据探查、问题诊断、名称标准化、规格标准化、合并去重五个清洗步骤。
6. AI 为原“未映射”数据自动建立映射，输出统一标准的商品清单。
7. 人工在清洗结果中修改标准名称或规格，并勾选需要确认的数据。
8. 只有勾选确认的数据才能进入可信商品库，并保留完整追溯信息。

## 可执行规则格式

- `名称映射：原名称 = 标准名称`
- `规格映射：原规格 = 标准规格`
- `忽略大小写` 或 `统一大小写`
- `忽略空格` 或 `移除所有空格`
- `统一规格`、`统一容量单位` 或 `单位换算`

规则只有保存为新版本后才能执行。规则优先参与匹配，规则未覆盖的数据由 AI 根据名称、规格和材料记录关系补充映射。

## 当前前端数据契约

### 材料

`id`、`name`、`type`、`size`、`sheets`、`rows`、`columns`、`status`、`data`。

### 清洗报告

- 原始数据：来源材料、原始行号和全部原始字段。
- 数据诊断：问题类型、影响、示例及影响记录数。
- 清洗步骤：步骤名称、操作说明及执行结果。
- 标准化结果：原始名称/规格、标准名称/规格、价格、AI 映射依据、置信度、确认状态和规则版本。

### 可信商品

`productCode`、`productName`、`specification`、`efficacy`、`price`、`sources`、`codeMappings`、`ruleVersion`、`confirmedAt`。

### 数据持久化

- SQLite 文件：`data/chengyan.db`。
- `trusted_products`：可信商品当前版本，以商品编码为唯一键更新。
- `import_batches`：每次确认入库的批次、来源文件、规则版本、数量和时间；在数据清洗模块底部展示最近批次。
- `import_items`：每个批次实际写入的商品快照。
- 上传材料和未确认的清洗状态只保存在当前浏览器页面，刷新后清空。
- 使用 `npm run dev` 同时启动网页和数据库 API。

## 当前边界

- 支持 `.xlsx` 与 `.csv`；旧版二进制 `.xls` 需要先转换格式。
- 当前 AI 清洗使用可解释的规则、标准单位转换和候选记录关系完成映射；尚未调用外部大模型服务。
- 当前数据库为本机 SQLite，适合本地演示和单机使用；多人在线部署时需要迁移到服务端数据库并增加用户权限。

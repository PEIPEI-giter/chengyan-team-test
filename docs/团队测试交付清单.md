# 团队测试交付清单

更新日期：2026-09-23

## 1. 代码包 / Git / Site

- 代码：GitHub 私有仓库 <https://github.com/PEIPEI-giter/chengyan-team-test>。
- 交付范围：整套“澄研智库”，包含工作台、商品库、商品数据清洗、团队协同、用户管理、Node API、SQLite 数据库与飞书同步逻辑，不是只交付“团队协同”模块。
- 本地开发站点：`http://127.0.0.1:5174`，运行 `npm run dev` 后访问。
- 本地生产站点：`http://127.0.0.1:5175`，先运行 `npm run build`，再运行 `npm start`。
- GitHub Pages 不适用：系统包含 Node API、SQLite 和飞书本地授权，不能作为纯静态站点运行。

## 2. 数据库相关文件

- 测试种子库：`data/seed/chengyan-test.db`。
- 运行库：`data/chengyan.db`，首次启动时由种子库自动生成，已加入 `.gitignore`。
- WAL/SHM、日志和导出结果为运行时文件，不提交 Git。
- 当前种子库包含：2 个测试用户、3 条可信商品、2 次导入批次、1 个真实目标、1 份飞书周报、30 条拆解事项及 1 条分析记录；不包含任何登录会话。

> 种子库包含团队测试用的飞书周报内容，只允许上传私有仓库，不应公开发布。

## 4. 部署说明

详见 [部署说明](部署说明.md)，包括整套系统的依赖安装、开发启动、生产启动、局域网共享、飞书授权、数据库初始化、健康检查和回滚方式。

当前 GitHub 私有仓库已经是可部署代码交付；公网部署仍需要一台可运行 Node.js 20+ 且可持久化 SQLite 文件的服务器。GitHub Pages、纯静态托管和无持久磁盘的 Serverless 平台不适用于当前架构。

## 建议测试路径

1. 分别使用管理员和成员账号登录、退出。
2. 管理员进入用户管理，新建一个测试用户并验证启停功能；成员账号确认没有用户管理入口。
3. 打开商品库，验证可信商品与导入批次能从 SQLite 读取。
4. 打开团队协同，确认步骤 1–4 均可看到周报分析记录。
5. 点击分析记录进入详情并返回。
6. 点击“新建内容”，确认进入空白目标表单且历史记录不丢失。
7. 使用有权限的飞书账号同步一份 Docx/Wiki 周报，确认拆解、人工确认、重新生成和保存流程。
